## ⚠️ Dev Smoke Artifacts (NOT submission metrics)

`dev_smoke_metrics.json` and `dev_smoke_stdout.txt` are **development-only** artifacts from an early pipeline run using **draft (keyword-generated) labels** — before human review. They show:

- `keyword accuracy=1.0` — **circular artifact**: the seed was generated by the same keyword heuristic, so it trivially scores 1.0 on its own labels
- `agent accuracy=0.605` — against draft labels, not human-approved labels
- `reply_judge.status=not_run` — no API key was set at the time

**The authoritative submission metrics are in `metrics.json`**, which uses the 200 human-approved golden labels and shows `keyword accuracy=0.785`, `agent accuracy=0.635`, and `reply_judge n=200, pass_rate=1.0`.
